# Shivam Rajput — portfolio

A complete, local-first Next.js App Router portfolio with React, TypeScript, self-hosted Inter, Lucide icons, and purpose-built CSS. No database, paid API, or external runtime service is required.

## Requirements

Node.js 20.9 or newer and npm. Node 22 or newer is recommended.

## Run locally

Open a terminal in this folder:

```sh
npm install
npm run dev
```

Open http://localhost:3000 (or the address Next.js prints if that port is already occupied).

## Production

```sh
npm run typecheck
npm run build
npm start
```

The project uses the standard Next.js Node server. Run the commands from this folder, not its parent. Keep the package-lock.json generated by the first successful install and use npm ci for subsequent reproducible installations. Dependencies use compatible version ranges; no lockfile is fabricated.

## Edit your content

**src/data/portfolio.ts** holds personal details, navigation, social URLs, skills, project descriptions and evidence links, education, and LeetCode data. Update this file first. The LeetCode numbers are a dated, supplied snapshot, not an API feed. Update the snapshot label when you refresh them. Language totals can overlap and must not be summed as unique solved problems.

- Replace **public/resume.pdf** with your next resume; the navigation uses that local PDF.
- Edit **src/app/globals.css** for colors, typography, spacing, and responsive layouts.
- Edit **src/components/** for section layouts and interactions.
- Edit **src/app/layout.tsx** for the page title, description, and social metadata.
- Set NEXT_PUBLIC_SITE_URL in .env.local when you know the final public domain. Canonical URLs and sitemap entries are intentionally omitted until a domain is supplied.

## Design and behavior

Charcoal, soft white, and one cyan accent. Editorial project cards expose engineering decisions and scope through native, keyboard-accessible disclosures. The hero visualization switches between projection and distribution views; both use explicitly synthetic data. LeetCode charts expose every numeric value in text. No fake contribution heatmap, testimonials, proficiency percentages, or project metrics are used.

The mobile navigation is an inline disclosure, not a modal. Escape closes it and returns focus to the toggle. Outside clicks and selecting a link close it. Desktop resizing resets its state. Native anchors preserve browser history and keyboard behavior.

Only the navigation and hero view toggle require client state. The content remains readable without JavaScript. The site respects reduced motion and includes visible focus indicators, a skip link, semantic sections, descriptive links, a custom favicon, basic error pages, Open Graph and X metadata, and Person structured data. Inter is served locally via the font package; the browser does not contact Google Fonts.

Responsive layouts cover 320, 375, 430, 768, 1024, 1280, and 1440+ pixels. There are no project screenshot or photo downloads; the diagram is a lightweight SVG and the project pipeline uses semantic HTML/icons.

## Deployment notes

This delivery is a local Node.js project. It has not been published. Use a Next.js-compatible Node host when ready. GitHub Pages requires a separate static-export configuration and base path; the current server configuration is not a direct Pages upload.

Review CONTENT-SOURCES.md and VALIDATION.md for provenance and the checks possible in the authoring environment.
